# Glossary

| Term | Meaning |
| ---- | ------- |
| ADR | Architecture Decision Record (`docs/adr/NNNN-<slug>.md`): context, decision, consequences, addenda |
| Adapter | Thin tool pointer file deferring to `AGENTS.md` (generated by `whw adapters sync`) |
| AGENTS.md | Canonical agent instructions at repo root (open convention) |
| Builder | Role: implements one claimed todo minimally, with evidence |
| Charter | Program ADR: outcome, exclusions, wave map, close criteria |
| Checkpoint | Timestamped gate verdict (`.whw/checkpoints/<gate>/latest.txt`) |
| Claim | `pending`/`blocked` → `in_progress` reservation by one agent |
| Closer | Role: lands waves canonically (checklist + `whw close`) |
| Custom gate | User shell command registered in `whw.config.json` (exit 0 = GO) |
| Done hook | `planning/<track>.done.sql`: close SQL applied only by `whw close` |
| Evaluator | Role: two-phase review (deterministic, then rubric) → APPROVE/REJECT |
| Evidence | Re-runnable proof (commits, PRs, checkpoints, test output) |
| Gate | Executable GO/NO_GO check (`whw gate run`) |
| Handoff | Tool-migration package (`whw handoff --from X --to Y`) |
| Letter | Wave step A–E (Plan, Build, Check, Decide, End) |
| Metrics | Reproducible repo numbers (`whw metrics`) |
| Planner | Role: idea → verifiable plan + seeds (no implementation) |
| Program | Bounded wave set under a charter ADR with exclusions |
| Queue | Actionable todos: `in_progress` + dependency-ready `pending` |
| Ready | `pending` todo whose deps are all `done`/`cancelled` (SQL view) |
| Ref | Todo id: `waveNNN-L` for waves, free-form otherwise |
| Role | Responsibility contract with context strategy + handoff files |
| Seed | Versioned `planning/*.todos.sql` intent file (applied by `whw sync`) |
| Skill | Agent Skills–compliant pack (`skills/<name>/SKILL.md`) |
| State | Derived SQLite DB (`.whw/state.db`): statuses, transitions, evidence |
| Sync gate | Gate keeping narrative (plan/README/ADR) aligned with state |
| Tier | Gate group: `pr` (blocking, lean) or `ops` (on demand) |
| Track | Todo grouping: wave track (`wave-NNN-slug`) or free-form ops track |
| Transitions | Append-only audit of status changes |
| Wave | Execution unit: one increment in five letters (A–E) |
| WHY | Purpose root (`WHY.md`): purpose, non-goals, principles |
