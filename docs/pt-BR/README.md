# WHW — jornada de adoção em português brasileiro

O WHW organiza trabalho humano e de agentes com propósito, decisões, estado
SQL e evidências. É indicado para desenvolvedores e líderes técnicos que
precisam retomar trabalho, trocar de ferramenta e revisar entregas rastreáveis.
O inglês é canônico; a jornada abaixo oferece adoção completa em pt-BR.

## O que está comprovado

Há provas públicas de adoção local, continuidade por arquivos/SQL, execução
Codex assistida pelo operador e publicação npm preparada por OIDC com
aprovação humana. Não equivalem a autonomia completa, conformidade empresarial,
economia financeira ou ganhos de benchmark. A comparação opt-in classic vs
shift-left é uma simulação regenerável, não esse ganho: [resumo](comparacao-shift-left.md).
Veja as evidências e limites no [README](../../README.pt-BR.md#evidências-e-limites).

## Convenção de idioma

Comandos e identificadores não são traduzidos. Referências técnicas e ADRs
históricos permanecem em inglês; cada guia sinaliza esses links. As melhorias
documentais estão no GitHub; o pacote npm 0.2.0 mantém os documentos da
publicação até o próximo release.
